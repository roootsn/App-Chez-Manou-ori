# Chez Manou : application de caisse et de gestion (PRIVÉ)

Application interne de Chez Manou Bar-Resto et du Dépôt Chez Manou : caisse, tables, stock, arrivages, fournisseurs, clients et crédits, fidélité, dépenses, rapports PDF, comptes avec 6 niveaux d'accès et journal d'activité.

**Ce dépôt doit rester privé.** Il est totalement séparé du site vitrine public.

Voir [GUIDE.md](GUIDE.md) pour l'installation et la sécurité.

## Présentation

Le dossier `docs/` contient la présentation du projet (`presentation-chez-manou.html`) et les captures d'écran, sur téléphone et sur ordinateur. Les écrans utilisent des données de démonstration.
